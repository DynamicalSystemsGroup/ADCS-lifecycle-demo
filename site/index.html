ADCS Lifecycle Demo

Evidence, attestation and requirements traceability, one satellite at a time

Michael Zargham · Dynamical Systems Group · OpenMBEE

The subject never changes. A geosynchronous communications satellite has an attitude determination and control system (ADCS): a PD controller with two gains, Kp and Kd. One requirement, REQ-001, says the pointing error must settle within 0.1° within 120 seconds of a slew. Symbolic analysis and simulation produce evidence about it. Sometimes the two disagree, and a person still has to judge whether the requirement is satisfied.

Evidence does not verify requirements; evidence supports a human judgment that requirements are satisfied.

This repository is a running workspace. The same example has been built for three audiences with three toolchains, and each version stays runnable: first a marimo notebook over RDF, then a Jupyter walkthrough, then a marimo deck with the model in SysML v2 itself. Start wherever suits you.
